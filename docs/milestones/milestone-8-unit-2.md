# Milestone 8 Unit 2: Community and Moderation

## Delivered
- Governed community spaces, threads, replies, evidence links, reports, moderation decisions, and non-authority reputation events.
- Religious claims require governed source evidence before publication.
- Takfir, dangerous content, self-awarded authority, and author self-moderation fail closed.
- Reports receive deterministic risk priority; every moderation decision records a policy code and reason.
- Community reputation measures constructive participation only and never represents scholarship, piety, or authority.

## Boundaries
- Community content is never canonical Islamic evidence.
- User reputation cannot promote a user into a scholar role.
- Child access is disabled by default.
- Live moderator operations, appeals, notification delivery, and abuse-rate limits remain future integration work.
