# Milestone 8 Unit 3: Scholarly Collaboration

This unit adds verified-profile metadata, versioned collaborative drafts, governed evidence links, independent review assignments, review outcomes, and final approval snapshots.

## Non-authority boundary
A verified profile is identity and credential metadata. It never automatically grants authority to issue rulings on behalf of the platform. Publication remains a governed editorial act requiring source evidence and independent review.

## Publication gate
A draft cannot be published without governed evidence, the configured number of independent Islamic and editorial approvals, one source-integrity approval, and zero unresolved rejections.

## Version integrity
Every version stores content and evidence fingerprints. Comparison exposes line changes and added or removed evidence before approval.
