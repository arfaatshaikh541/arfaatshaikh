# Tafsir import governance

Tafsir is staged before publication. A deterministic manifest binds each canonical reference, exact UTF-8 text checksum, provenance passage, volume, and section. Validation reconciles expected entry, volume, and section counts and rejects conflicting hierarchy metadata or stale/cross-edition evidence.

Publication requires three independently attributed review domains: `tafsir_text`, `arabic_language`, and `source_provenance`. The approved source edition and manifest are revalidated immediately before one atomic canonical publication transaction. Import lifecycle events are append-only.

No AI-generated commentary, inferred scholarly position, or unlicensed corpus is accepted by this workflow.
