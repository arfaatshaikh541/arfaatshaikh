# Tafsir cross-reference and topic graph

Milestone 5 Unit 3 introduces a reviewed editorial graph across published Qur'an ayahs, hadith narrations, tafsir entries, and sourced topics.

## Trust rules

- Every topic has a current passage from an approved, ingestion-ready, retrieval-eligible source edition.
- Every cross-reference has an evidence passage and written rationale.
- Editorial confidence describes confidence in the linkage only. It never measures theological truth, hadith authenticity, or certainty of revelation.
- A reference remains private until a platform administrator reviews it and both linked entities are published.
- `asbab_al_nuzul` is only a relationship type. It does not assert a report is authentic without the linked attributed evidence.
- Conflicting scholarly relationships may coexist as separately attributed records.

## Public discovery

Public APIs expose published topics, reviewed cross-references, tafsir entries covering an ayah, and publication-only tafsir search. No AI-generated explanation or inferred consensus is produced.
