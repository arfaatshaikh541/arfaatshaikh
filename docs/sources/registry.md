# Islamic source registry

The registry separates a conceptual source from a specific edition. Approval is edition-specific because publishers, translators, editors, numbering systems and licence terms can differ.

Registration never implies authority, legality or retrieval eligibility. New sources begin `unassessed`; new editions begin `pending` and `approved_for_retrieval=false`.

A source edition becomes retrieval-eligible only after legal review, integrity verification, domain review and an explicit approval transition implemented in a later Milestone 2 unit. No Qur'an, hadith or classical corpus content is included in this unit.
