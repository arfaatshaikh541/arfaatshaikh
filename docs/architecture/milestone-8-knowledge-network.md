# Milestone 8 Unit 4: Knowledge Network

The canonical network maps governed domain records to immutable canonical keys. Relationships are typed, independently reviewable, and require a current governed source passage. Community posts, learner notes, annotations, and other user-generated content are excluded from evidence and search indexing.

Traversal is bounded to depth 5 and 500 nodes per request. Public APIs must return published entities and approved relationships only. Search planning supports Arabic normalization, English, transliteration, exact phrases, entity filters, and evidence-only mode. Semantic/vector indexing remains an adapter boundary and must never bypass publication or provenance gates.
