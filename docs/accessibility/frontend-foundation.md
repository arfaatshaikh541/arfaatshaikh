# Frontend accessibility foundation

Milestone 1 targets WCAG 2.2 AA. Unit 5 establishes semantic landmarks, visible keyboard focus, a skip link, form labels and error associations, status announcements, reduced-motion support, increased-contrast support, colour-independent text labels, responsive reflow, and document-level language/direction.

Arabic uses `lang="ar"` and `dir="rtl"` at the HTML boundary. Interface order relies on logical CSS properties so direction changes do not require mirrored component implementations.

Automated checks do not replace manual keyboard, screen-reader, zoom, contrast, and bidirectional-content review. Those checks remain part of Unit 6 hardening.
