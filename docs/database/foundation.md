# Database foundation

Milestone 1 Unit 2 introduces a single asynchronous SQLAlchemy engine and session factory.
Application code receives an `AsyncSession` through dependency injection. Transactional service
operations may use `UnitOfWork`, which commits only when the operation exits successfully and
rolls back on every exception.

## Conventions

- UUID primary keys are generated by the application.
- Timestamps use timezone-aware PostgreSQL values.
- Constraint names are deterministic for reliable Alembic diffs.
- Schema changes are migration-only. Runtime table creation is forbidden.
- Sessions are short-lived and never stored in global request state.
- The shared engine is disposed during application shutdown.
