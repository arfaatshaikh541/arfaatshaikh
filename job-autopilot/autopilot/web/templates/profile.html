Key conventions
  • identity: full_name, first_name, last_name, preferred_name, nationality · contact: email, phone, city, country, address_line, postal_code, linkedin_url, github_url, portfolio_url
  • work_authorization: authorized:united arab emirates = yes/no, requires_sponsorship:united arab emirates = yes/no

  • education (group): degree, field, institution, graduation_year · skill: key = skill name, value = professional / academic / personal · skill_years: key = skill, value = professional years
  • certification: key = name, value = issuer/date · language: key = language, value = proficiency · narrative: summary written by you · eeo: gender, ethnicity, veteran, disability (only if you want to answer)
