# @gridkeep/connector-sdk

Provider-neutral connector SDK (base `Connector` ABC, `ConnectorDefinition`
protocol, mock-connector contract test harness) — see
`docs/architecture/gridkeep-architecture.md` §12 for the design.

**Status: out of scope for Milestone 1.** This package is scaffolded as an
empty placeholder so the repository structure matches the approved
architecture. Implementation begins in Milestone 2 (Integration SDK and
Asset Graph) and will include the connector base classes, mock connectors,
and the shared connector contract-compliance test suite. No code here is
referenced by Milestone 1 modules.
