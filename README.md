## GRIDKEEP Sovereign AI Network Exchange

A federated sovereign-AI infrastructure platform for telecom operators to expose and commercialise GPU/CPU capacity,
Kubernetes clusters, edge compute, and confidential-computing nodes to enterprises and governments under strict
sovereignty, security, and contractual governance.

This repository hosts the monorepo. See:

- `docs/architecture/` — system architecture, ER diagrams, data flow
- `docs/adr/` — architecture decision records
- `docs/project-status.md` — live milestone status, acceptance criteria, risks
- `apps/` — deployable services (`web`, `control-api`, `policy-engine`, `worker`, ...)
- `packages/` — shared libraries and contracts
- `infrastructure/` — Docker, Kubernetes, Helm, Terraform, CI policy

Local development: see `docs/operations/local-development.md`.
